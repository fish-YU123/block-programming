# 开发路线图

## M1 世界与地图（已完成）

- [x] 方块数据表（9 种方块，JSON 定义）
- [x] 256×256×64 有限世界，噪声地形、沙滩、矿脉
- [x] 区块网格与碰撞，256 区块常驻，60fps
- [x] 自由视角相机、挖掘、放置
- [x] 中立区禁建规则
- [x] 蓝/红分界细线（跟随地形、改方块自动重铺）

- [ ] 部件数据表：轮子、推进器、电池、控制中心、传感器

- [ ] 单位物理：刚体 + 轮子驱动 + 推进器
- [ ] 单位渲染：部件摆放在单位节点下
- [ ] 部署：把蓝图变成地图上的单位实例
- [ ] 传感器读数：位置/速度/朝向/电量/部件状态

## M3 玩家代码接入

- [ ] 单位绑定控制中心 → 每个控制中心一个 VM 实例
