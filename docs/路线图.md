- [x] 传感器：位置/速度/朝向/电量/推力/雷达 5×5 方块与高度/敌方单位

## M4 资源与生产（已完成第一版）

- [x] 挖掘产出矿石进入队伍仓库（煤矿/铜矿）
- [x] 放单位扣资源、收回退款、资源不足提示
- [x] 生产线骨架：配方（输入→输出→耗时）与 tick
- [x] 建筑数据表 `data/buildings/*.json`（采矿机、组装厂）
- [x] 建筑放置（Q 切换 / B 放 / N 拆退款）：只能建在自己半场、占位必须是空的、不与已有建筑重叠
- [x] 铁矿 / 金矿（更深的矿脉，进资源链）
- [x] 充电站（半径 14 米给己方单位补电）
- [x] 采矿机：每 1.2 秒挖掉正下方一块方块并进账（挖到基岩停）
- [x] 组装厂：每 18 秒花一台飞飞的造价，在厂房旁边下线一台飞飞（受单位上限限制）
- [ ] 建筑血量与可破坏（现在建筑打不掉）
- [ ] 更多建筑（发电、充电、雷达站）与建筑配方链
