# 飞飞快速上手：怎么让无人机飞起来

游戏里每台飞飞跑的是**你自己写的一段代码**。代码跑在游戏的沙箱里，
**每秒执行 60 行**（不是每帧 60 行，是每秒总共 60 条语句）。

在游戏里按 **C** 打开右边的代码面板，改完点「应用代码」（或 ⌘+回车）立刻生效。
也可以直接**双击画面里自己的飞飞**打开它的代码。

---

## 一、代码长什么样

每台单位的代码由两个函数组成：

```python
def start():
    # 只跑一次：开局、或者你点了「应用」之后的第一件事
    print("起飞")

def loop():
    # 一直跑：这段会被反复执行，直到单位被击毁或者你改代码
    set_lift(0.6)
```

- `start()` 可以完全不写；不写就只跑 `loop()`。
- 两个都不写也行：那就跟以前一样，整段代码循环执行。
- **`start()` 里的变量如果要留给 `loop()`，放进 `mem`**（见第四节）。
- `print()` 的内容显示在面板下方的「print 输出」里，调试很有用。

> 每秒 60 行的意思：如果你在 `loop()` 里写了 10 行，那么每秒大约跑 6 次；
> 写了 30 行就是每秒 2 次。想让它反应更快，就把 `loop()` 写短一点。

## 二、控制指令（六个）

| 指令 | 作用 | 取值范围 |
| --- | --- | --- |
| `set_lift(升力)` | 底部矢量喷口的推力大小 | 0 ~ 1，飞飞满推 520 牛 |
| `set_tilt(前后, 左右)` | 喷口偏转方向（矢量喷口） | 各 -1 ~ 1，正数 = 往前/往左 |
| `set_rcs(转向, 前后)` | 两侧小喷口，转向和前后微调 | 各 -1 ~ 1 |
| `drill(True/False)` | 开/关前置激光钻头 | `True` 开，`False` 关 |
| `laser(x, y, z)` | 朝一个方块坐标打激光，5 格射程，持续掉血 | 关掉用 `laser_off()` |
| `shoot(x, y, z)` | 炮管朝一个方块坐标开一炮，15 格射程，1 秒冷却 | 每打一发消耗 2400 焦耳 |

飞飞自重 12kg，重力 24 m/s²，满推力 520 牛 ≈ 能推起 21kg。
所以**悬停大概需要 `set_lift(0.57)` 左右**，再靠比例微调。

## 三、最小可用：起飞并悬停

```python
def loop():
    # 目标是「脚下地表 + 8 米」
    目标高度 = heights[2][2] + 8
    误差 = 目标高度 - pos.y
    # 低了多推、高了少推；再减去上升速度，防止冲过头
    set_lift(0.57 + 误差 * 0.15 - vel.y * 0.1)
```

这三行就是飞飞的自动驾驶基础，下面所有例子都是在这个上面加东西。

## 四、记忆：`mem`

`mem` 是一个字典，**重新开始（跑完 loop 再跑 loop、或者 start 换 loop）时不会被清空**：

```python
def start():
    mem["阶段"] = 0
    mem["起点x"] = pos.x

def loop():
    if mem["阶段"] == 0:
        # 起飞
        set_lift(0.8)
        if pos.y > heights[2][2] + 6:
            mem["阶段"] = 1
    else:
        # 悬停
        set_lift(0.57 - vel.y * 0.1)
```

## 五、传感器（每帧自动更新，直接当变量用）

| 变量 | 内容 |
| --- | --- |
| `pos.x / pos.y / pos.z` | 世界坐标（米） |
| `vel.x / vel.y / vel.z` | 速度（米/秒） |
| `cell.x / cell.y / cell.z` | 所在方块格 |
| `yaw` | 朝向（弧度） |
| `energy` / `energy_ratio` | 剩余电量（焦耳）/ 0~1 |
| `thrust` | 当前实际推力（牛） |
| `drill_hits` | 一共钻掉多少方块 |
| `blocks[i][j]` | 雷达 5×5 表面方块名字符串，`[2][2]` 自己脚下 |
| `heights[i][j]` | 雷达 5×5 的地表高度 |
| `here` | 正下方方块名 |
| `blocks3[i][j][k]` | 雷达 5×5×5 三维方块名，`[2][2][2]` 是自己所在格 |
| `enemies` | 10 格内的敌方单位（最近的在前），每项有 `.x .y .z .type .hp .dist` |

## 六、飞过去：`go_to(x, y, z)`

这是一条命令就能到位的：**自动 A\* 寻路**，会自己绕开山体和方块，不需要你算倾角。

```python
def loop():
    go_to(64, 32, 128)      # 飞到世界坐标 (64, 32, 128)
```

- 飞行途中 `moving` 会是 `True`，到了就变回 `False`
- 想停下来就调 `stop()`
- 目标在方块里面的话，会自动往上找到最近的一个空气格

### 想自己搓飞行：`find_path` + `set_velocity` + `set_altitude`

`go_to` 是"一行版"自动驾驶（它内部就是 A* + 顺着航路飞）。如果你想自己写飞行逻辑，可以只要航路，剩下的自己下指令：

```python
def loop():
    # 1) 让 A* 算一条绕开障碍的航路（返回 [{x,y,z}, ...]，已经抽稀过）
    航路 = find_path(64, 32, 128)
    if len(航路) > 0:
        点 = 航路[0]                       # 先飞向第一个路点
        差x = 点.x - pos.x
        差z = 点.z - pos.z

        # 2) 定一个"想达到的水平速度"，引擎每帧自动闭环（不会抖）
        想x = max(-6, min(6, 差x * 1.5))
        想z = max(-6, min(6, 差z * 1.5))
        set_velocity(想x, 想z)
        set_altitude(点.y)                 # 想稳定在这个高度
```

- `set_velocity(vx, vz)`：世界坐标下的目标水平速度（米/秒），无人机会自己倾转去追这个速度
- `set_altitude(y)`：目标世界高度，自己配升力
- 两个都是"持续指令"：设一次会一直生效，直到你再改或断电
- 也可以完全手动：`set_lift(0~1)` / `set_tilt(前后, 左右)` / `set_rcs(转向, 前后)`（`set_tilt` 的"前后"是世界 X、"左右"是世界 Z；红方朝反方向时符号相反）

**注意**：`go_to` 自动驾驶会接管 `lift/pitch/roll`，同一段代码里不要又 `go_to` 又 `set_velocity`。

## 七、钻地 / 挖矿

```python
def loop():
    目标高度 = heights[2][2] + 1.2   # 贴地飞
    误差 = 目标高度 - pos.y
    set_lift(0.57 + 误差 * 0.15 - vel.y * 0.1)
    drill(True)                      # 一直开着钻头
```

钻头在机头前方 1.5 米内打到方块就会挖掉，挖掉的东西直接进仓库
（煤、铜…）。电量每秒掉一点，`energy_ratio` 低于 20% 就省着点用。

## 八、用激光挖矿 / 用炮打人

激光和炮管都要**给一个目标坐标**，它们会自动朝那个方向打，打到第一个碰到的东西为止。

挖一条石头隧道（朝正前方 4 格）：

```python
def loop():
    set_lift(0.6)
    # 朝自己正前方 4 格的方向打激光（连打，每帧都在掉血）
    laser(pos.x + 4, pos.y, pos.z)
```

停下来就关掉：

```python
    laser_off()
```

远处看到敌人就打炮（雷达能看到 10 格内的敌人）：

```python
def loop():
    set_lift(0.6)
    if len(enemies) > 0:
        敌 = enemies[0]
        shoot(敌.x, 敌.y, 敌.z)
```

三种攻击的区别：

| 手段 | 射程 | 怎么生效 |
| --- | --- | --- |
| `drill(True)` | 贴身 1.5 格 | 每 0.25 秒挖掉一整格 |
| `laser(x,y,z)` | 5 格 | 持续光束，每秒对块 80 / 对单位 22 |
| `shoot(x,y,z)` | 15 格 | 单发，对块 60 / 对单位 34，冷却 1 秒 |

## 九、干活：读玩家的标记

玩家在地图上点出来的挖掘/放置/建造/拆除，都只是**虚影**，真正的活要单位去做。
这些标记在代码里就是 `orders`（按距离排好序的列表）：

| 字段 | 意思 |
| --- | --- |
| `orders[0].x/y/z` | 标记所在格子的坐标（整数） |
| `orders[0].action` | `"mine"` 挖 / `"place"` 放 / `"build"` 建 / `"remove"` 拆 |
| `orders[0].id` | 方块或建筑的名字，比如 `"stone"`、`"factory"` |
| `orders[0].dist` | 距离你多远 |

骨架代码（预设代码里已经有）：

```python
def loop():
    if len(orders) > 0:
        单 = orders[0]
        # 飞过去：把目标设成标记点
        # 到了就动手：
        if 单.action == "mine" and 单.dist < 3:
            drill(True)                       # 贴身钻头
            laser(单.x + 0.5, 单.y + 0.5, 单.z + 0.5)   # 或者激光挖
```

标记变成现实、或者已经不需要了，会自动从 `orders` 里消失。

## 十、追着敌人钻

```python
def loop():
    目标高度 = heights[2][2] + 8
    误差 = 目标高度 - pos.y
    set_lift(0.57 + 误差 * 0.15 - vel.y * 0.1)

    if len(enemies) > 0:
        敌 = enemies[0]              # 最近的一台
        距离 = 敌.x - pos.x
        想要 = max(-6, min(6, 距离 * 1.2))   # 靠近了就别冲太快
        if abs(距离) < 1.5:
            想要 = 0
        set_tilt(max(-1, min(1, (vel.x - 想要) * 0.08)), 0)
        drill(abs(距离) < 2.5)       # 贴上去开钻
    else:
        set_tilt(0, 0)
        drill(False)
```

## 十一、能用的语法（Python 子集）

支持：`if / elif / else`、`while`、`for i in range(...)`、`def`、`break`、`continue`、
列表、字典、字符串、`+ - * / // % **`、比较、`and/or/not`、`in`、中文变量名。
内置函数：`print`、`len`、`abs`、`min`、`max`、`int`、`float`、`str`、`round`、`bool`、`range`。

不支持（写了会报错，不会崩溃）：`import`、`class`、`lambda`、`try`、`with`、
`yield`、`global`、`async`、f-string、三引号字符串。

## 十二、出错怎么办

- 出错时单位会**停住不动**，面板上显示 `第 N 行 错误类型: 说明`
- 改完点「应用」就会重新加载，错误清空
- 死循环不会卡死游戏：行数预算用完这一帧就停，下一帧接着跑
- 电量耗尽的单位不执行代码、也没有推力 —— 落在原地等修

更完整的语言参考见 [单位编程手册.md](单位编程手册.md)。
