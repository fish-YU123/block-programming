# 单位编程手册（沙箱脚本语言 v1）

游戏里每个"控制中心"跑一段玩家写的代码，每秒执行 60 行（60 条语句）。
语言是 Python 的受限子集，跑在我们自己实现的沙箱字节码虚拟机里：
**没有文件、没有网络、没有 import，玩家代码不可能碰到电脑或游戏本体。**

## 一、能用的语法

```python
# 注释
x = 1                 # 赋值
x += 1                # 增强赋值：+ - * / // % **
a, b = 1, 2           # 元组赋值

if x > 2:
    y = 1
elif x == 2:
    y = 2
else:
    y = 3

while x < 10:         # while 循环
    x += 1

for i in range(3):    # range(终点) / range(起点, 终点) / range(起点, 终点, 步长)
    print(i)

def add(a, b=2):      # 函数，支持默认参数
    return a + b

break / continue / pass
```

**明确不支持**（写了会给出中文提示，不会崩溃）：
`import`、`class`、`lambda`、`try/except`、`with`、`yield`、`global`、
`async/await`、f-string、三引号字符串、链式比较（`a < b < c`）。

## 二、数据类型与运算

- 数字：整数 `1`，小数 `1.5`；`/` 得到小数，`//` 向下取整，`%` 取余（符号跟着除数）
- 字符串：`"abc"`、`'abc'`；`+` 拼接，`*` 重复，`%` 做简单格式化
- 列表：`[1, 2, 3]`，可下标读写（负下标可用）
- 字典：`{"k": 1}`，可下标读写，`in` 判断键
- 布尔：`True` / `False` / `None`；`and` / `or` / `not`
- 成员判断：`x in 列表`、`"a" in 字典`、`x not in ...`

内置函数：`print`、`len`、`abs`、`min`、`max`、`int`、`float`、`str`、`round`、`bool`、`range`。

## 三、控制单位

```python
set_drive(1)              # 所有轮子一起转，-1~1
set_spin(序号, 弧度每秒)   # 单独控制某个轮子的转速
set_steer(序号, 角度)      # 转向
set_thrust(序号, 牛)       # 螺旋桨推力
get_link(1)               # 取第 1 个链接的部件
```

部件也可以直接用名字访问（第 3 个轮子叫 `wheel3`）：

```python
get_link(1).speed = 2     # 等价于 wheel1.speed = 2
wheel1.steer = 15
propeller1.thrust = 3
```

- 轮子：`speed` 是弧度每秒，`steer` 是角度
- 螺旋桨：`speed` 就是推力（牛），也可以用 `thrust`
- 读同样的属性可以得到当前命令值

## 四、传感器（装上才有对应全局变量）

| 部件 | 变量 |
| --- | --- |
| GPS | `px py pz` |
| 线速度传感器 | `vx vy vz ax ay az` |
| 角度传感器 | `yaw pitch roll`（度）、`wx wy wz` |

另外始终有：`energy`（剩余焦耳）、`wheels`（轮子数）、`props`（螺旋桨数）。

## 五、存档：`mem`

`mem` 是一个字典，程序跑完重新开始时会保留：

```python
if "n" in mem:
    mem["n"] += 1
else:
    mem["n"] = 1
```

## 六、运行规则与限制

- 每个控制中心**每秒 60 行**，帧率低时会按预算补齐（单帧最多补 4 步）
- 程序执行到结尾会**自动从头再跑一遍**，`mem` 保留
- 死循环不会卡住游戏：行数预算用完后本帧停止，下一帧继续
- 单条语句占用的资源有上限（例如超长字符串/列表会报"内存保护"错误）
- 运行出错时程序会停下并在编辑器下方显示 `第 N 行 错误类型: 说明`；
  改代码保存后会自动重新加载
- 电量为 0 的单位不执行代码

## 七、完整例子：沿着 +X 走，撞墙就转向

```python
# 用 GPS 的 x 坐标判断走了多远
if not "last_x" in mem:
    mem["last_x"] = 0

if px - mem["last_x"] < 0.5:
    set_steer(1, 25)     # 原地拧一下轮子
else:
    set_steer(1, 0)
    set_drive(1)

mem["last_x"] = px
```
