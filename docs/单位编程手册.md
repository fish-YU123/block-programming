# 单位编程手册（沙箱脚本语言 v1）

游戏里每个单位跑一段玩家写的代码，**每秒执行 60 行**（60 条语句）。
入门教程见 [飞飞快速上手.md](飞飞快速上手.md)。

## 零、两个固定函数

```python
def start():   # 开局 / 点「应用」之后跑一次
    ...

def loop():    # 之后一直反复跑
    ...
```

只写 `loop()` 也可以；两个都不写就整段代码从头循环（老写法）。

语言是 Python 的受限子集，跑在我们自己实现的沙箱字节码虚拟机里：
**没有文件、没有网络、没有 import，玩家代码不可能碰到电脑或游戏本体。**

## 一、能用的语法

```python
# 注释
x = 1                 # 赋值
x += 1                # 增强赋值：+ - * / // % **
a, b = 1, 2           # 元组赋值

if x > 2:
    y = 1
elif x == 2:
    y = 2
else:
    y = 3

while x < 10:         # while 循环
    x += 1

for i in range(3):    # range(终点) / range(起点, 终点) / range(起点, 终点, 步长)
    print(i)

def add(a, b=2):      # 函数，支持默认参数
    return a + b

break / continue / pass
```

**明确不支持**（写了会给出中文提示，不会崩溃）：
`import`、`class`、`lambda`、`try/except`、`with`、`yield`、`global`、
`async/await`、f-string、三引号字符串、链式比较（`a < b < c`）。

## 二、数据类型与运算

- 数字：整数 `1`，小数 `1.5`；`/` 得到小数，`//` 向下取整，`%` 取余（符号跟着除数）
- 字符串：`"abc"`、`'abc'`；`+` 拼接，`*` 重复，`%` 做简单格式化
- 列表：`[1, 2, 3]`，可下标读写（负下标可用）
- 字典：`{"k": 1}`，可下标读写，`in` 判断键
- 布尔：`True` / `False` / `None`；`and` / `or` / `not`
- 成员判断：`x in 列表`、`"a" in 字典`、`x not in ...`

内置函数：`print`、`len`、`abs`、`min`、`max`、`int`、`float`、`str`、`round`、`bool`、`range`。

## 三、控制单位（飞飞）

```python
set_lift(0.6)         # 升力 0~1，把推力按比例开到最大推力的 60%
go_to(64, 32, 128)    # 自动驾驶（A* 寻路）飞到这个世界坐标
find_path(x, y, z)    # 只算航路，返回 [{x,y,z}, ...]（自己控制时用）
set_velocity(vx, vz)  # 目标水平速度（世界坐标，米/秒），每帧自动闭环
set_altitude(y)       # 目标世界高度，自动配升力
stop()                # 停下自动驾驶
set_tilt(前倾, 侧倾)   # 各 -1~1；前倾让喷口向前偏，侧倾让它向左偏
set_rcs(转向, 前后)    # 两侧小喷口，各 -1~1；前后 = 沿机身前后微调
drill(True)            # 开/关激光钻头（钻地面方块，也打贴身的敌方单位）
laser(x, y, z)         # 朝某个方块坐标打激光：5 格射程，打到第一个方块/单位就持续伤害
laser_off()            # 关掉激光
shoot(x, y, z)         # 炮管朝某个方块坐标开一炮：15 格射程，冷却 1 秒，单发伤害
```

### 三种攻击手段的区别

| 手段 | 射程 | 方式 | 适合 |
| --- | --- | --- | --- |
| `drill` | 贴身 1.5 格 | 每 0.25 秒挖掉一格 | 边走边挖、近战 |
| `laser(x,y,z)` | 5 格 | 持续光束，每帧都在掉血 | 隔空挖矿、追着敌方烤 |
| `shoot(x,y,z)` | 15 格 | 单发，有 1 秒冷却，消耗 2400 焦耳 | 远程点杀、拆建筑 |

激光和炮管都只打**第一个碰到的东西**——挡在中间的方块会先挨打。方块也有血量：

| 方块 | 血量 |
| --- | --- |
| 草 / 泥土 / 沙子 | 18 |
| 木板 | 36 |
| 石头 | 42 |
| 煤矿 | 60 |
| 铜矿 | 72 |
| 基岩 | 打不动 |

激光每秒对**方块** 80、对**单位** 22；炮管一发对**方块** 60、对**单位** 34。
激光往哪打：`laser(pos.x + 5, pos.y, pos.z)` 就是朝自己正前方 5 格打。

推力方向 = 喷口方向，最大推力来自单位数据（飞飞 520 牛，自重 12kg，重力 24）。

## 四、传感器（每帧自动更新，直接当变量用）

| 变量 | 内容 |
| --- | --- |
| `pos.x / pos.y / pos.z` | 单位世界坐标（米） |
| `vel.x / vel.y / vel.z` | 速度（米每秒） |
| `cell.x / cell.y / cell.z` | 单位所在的方块格坐标 |
| `yaw` | 朝向（弧度，绕 Y 轴） |
| `energy` / `energy_ratio` | 剩余电量（焦耳）/ 百分比 0~1 |
| `thrust` | 当前实际推力（牛） |
| `drill_hits` | 累计钻掉的方块数 |
| `blocks[i][j]` | 雷达 5×5 范围（以单位为中心）的表面方块名，字符串 |
| `heights[i][j]` | 同上位置的地表高度（方块格 y） |
| `here` | 单位正下方表面的方块名 |
| `blocks3[i][j][k]` | 雷达 5×5×5 三维方块名，`[2][2][2]` 是自己所在格 |
| `enemies` | 10 格内的敌方单位，按距离排序，最近的在 `enemies[0]` |
| `orders` | 玩家标记的虚影指令，按距离排序，最近的在 `orders[0]` |
| `moving` | 自动驾驶是否还在飞（`go_to` 途中是 `True`） |

雷达下标：`[2][2]` 是自己脚下，`[0][0]` 是左下角，`[4][4]` 是右上角。

`blocks3` 的下标：`i` 是 x 方向、`j` 是 y（上下）、`k` 是 z 方向，范围都是 0~4，对应相对单位的 -2~+2 格。
比如 `blocks3[2][2][2]` 是单位自己所在那一格，`blocks3[3][2][2]` 是 +x 方向一格。

`orders` 里每一项是 `{x, y, z, action, id, dist}`，`action` 是 `"mine"`（挖）、`"place"`（放方块）、`"build"`（建建筑）、`"remove"`（拆建筑），`id` 是方块/建筑的名字。**玩家自己不会动手，他们只是打标记，这些活要你的代码去干。**

`enemies` 里每一项是 `{x, y, z, type, hp, dist}`：

```python
if len(enemies) > 0:
    敌 = enemies[0]
    print(敌.type, 敌.hp, 敌.dist)
```

`type` 是单位类型（目前都是 "feifei"），`hp` 是它当前血量（满血 120），`dist` 是距离（米）。

## 五、存档：`mem`

`mem` 是一个字典，程序跑完重新开始时会保留：

```python
if "n" in mem:
    mem["n"] += 1
else:
    mem["n"] = 1
```

## 六、运行规则与限制

- 每个单位**每秒 60 行**，帧率低时会按预算补齐（单帧最多补 4 步）
- 程序执行到结尾会**自动从头再跑一遍**，`mem` 保留
- 死循环不会卡住游戏：行数预算用完后本帧停止，下一帧继续
- 单条语句占用的资源有上限（例如超长字符串/列表会报"内存保护"错误）
- 运行出错时程序会停下并在代码面板里显示 `第 N 行 错误类型: 说明`；
  改代码点「应用」后自动重新加载
- 电量为 0 的单位不再产生推力

## 七、完整例子：悬停在离地 8 米，靠近敌人就钻

```python
while True:
    # 高度：目标 = 脚下地表 + 8 米
    目标 = heights[2][2] + 8
    误差 = 目标 - pos.y
    set_lift(0.57 + 误差 * 0.15 - vel.y * 0.1)

    # 水平：有敌人就朝它飞（x 方向），没有就原地悬停
    期望速度 = 0.0
    if len(enemies) > 0:
        距离 = enemies[0].x - pos.x
        期望速度 = max(-6, min(6, 距离 * 1.0))
        drill(abs(距离) < 2.5)
    else:
        drill(False)
    set_tilt(max(-1, min(1, (vel.x - 期望速度) * 0.08)), 0)

    # 抵消侧向漂移
    set_rcs(0, -vel.z * 0.6)
```
