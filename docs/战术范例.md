# 战术范例：把兵种用代码组合起来

这份文档给的是**可以直接抄进代码面板**的片段。核心思路都一样：

- 侦察机、干扰机这类单位自己不打人，它们提供**情报/干扰**
- 炮艇、自爆机、钻地机它们提供**火力**
- 用 `mark` / `team_set` / `command` 把两边连起来

---

## 一、侦察机报点，炮艇越视距打击

**侦察机**（视野 26 米，没武器）：

```python
def start():
    mem["方向"] = 1

def loop():
    地面 = heights[2][2]
    set_altitude(地面 + 22.0)
    if pos.x > 210.0:
        mem["方向"] = -1
    if pos.x < 46.0:
        mem["方向"] = 1
    set_velocity(22.0 * mem["方向"], 4.0)
    if len(enemies) > 0:
        敌 = enemies[0]
        mark(敌.x, 敌.y, 敌.z, "敌人")        # 报点
        team_set("敌情", len(enemies))

**炮艇**（自己雷达 12 米，看不见远处）：

```python
def loop():
    地面 = heights[2][2]
    if len(enemies) == 0 and len(marks) > 0:
        标 = marks[0]
        set_altitude(地面 + 10.0)
        if 标.dist > 20.0:
            set_velocity((标.x - pos.x) * 0.8, (标.z - pos.z) * 0.8)
        else:
            set_velocity(0.0, 0.0)
            shoot(标.x, 标.y, 标.z)
        return
    # 自己能看到敌人就正常打（略）
```

## 二、干扰机 + 自爆机：让敌人反应不过来

**干扰机**：贴近敌人，把对方代码执行速度压到 55%（`jam_slow`）。

**自爆机**：借干扰造成的反应延迟冲进去自爆。

```python
def loop():
    if len(enemies) == 0:
        set_velocity(20.0, 0.0)      # 没目标就往前压
        return
    敌 = enemies[0]
    set_altitude(敌.y + 1.0)
    set_velocity((敌.x - pos.x) * 1.2, (敌.z - pos.z) * 1.2)
    if 敌.dist < 2.5:
        explode(True)                # 贴脸引爆
```

## 三、钻地机潜航偷袭

水下雷达看不见单位，钻地机（`dive: true`）可以横穿湖泊，绕到敌人后方再破土。

```python
def loop():
    # 保持在水面以下：海平面 21 层，潜到 18 左右
    if submerged == 0 and water > 0.0:
        set_lift(0.0)
        set_altitude(18.0)
    if len(enemies) == 0:
        set_velocity(14.0, 0.0)
        return
    # 到敌人脚下了就往上钻
    敌 = enemies[0]
    set_altitude(敌.y + 0.5)
    set_velocity((敌.x - pos.x) * 1.0, (敌.z - pos.z) * 1.0)
    drill(True)
```

## 四、指挥官用 `command` 调度全部队友

指挥官（`leader == 1`）能看到全队，用 `command` 指着目标让所有人集火：

```python
def loop():
    if len(enemies) == 0:
        return
    敌 = enemies[0]
    for 友 in allies:
        command(友.uid, "attack", 敌.x, 敌.y, 敌.z)
    # 自己也打
    set_altitude(敌.y + 2.0)
    shoot(敌.x, 敌.y, 敌.z)
```

## 小抄

| 想做什么 | 用什么 |
| --- | --- |
| 告诉别人一个位置 | `mark(x, y, z, "标签")` |
| 读队友的标记 | `marks[0]` |
| 共享一个状态（比如"该撤退了"） | `team_set` / `team_get` |
| 直接命令某个队友 | `command(uid, "goto"/"attack"/"hold", x, y, z)` |
| 知道队友是谁 | `allies`（含 `uid`、`type`、`hp`、`dist`） |
| 水下的自己 | `water`、`submerged` |
