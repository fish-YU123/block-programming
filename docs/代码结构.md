# 代码结构

> 一句话：**一个 main 场景驱动世界 / 单位 / 建筑 / 联机，玩家写的代码在沙箱 VM 里跑，VM 通过「传感器 + 控制指令」跟游戏通信。**

```
main.tscn ── main.gd ─┬─ VoxelWorld（体素世界：区块网格、碰撞、DDA 射线）
                      ├─ TerrainGen（噪声地形 + 矿脉）
                      ├─ units[]（Flyer / Rover，各带 UnitController）
                      │     └─ UnitController ── PyVM（沙箱字节码虚拟机，跑玩家 Python 子集）
                      ├─ buildings[]（Building：施工进度、地基校验、动画）
                      ├─ Economy ×2（蓝/红各自的资源账）+ Production（配方）
                      ├─ MpManager（联机：主机权威 + 20Hz 快照）
                      └─ HUD / CodePanel / MpPanel（CanvasLayer UI）
```

## 目录职责

| 路径 | 职责 |
| --- | --- |
| `scripts/core/main.gd` | 游戏主循环与总装配：输入、相机、标记系统、单位/建筑/战斗/胜负、联机接线 |
| `scripts/core/mat_cache.gd` | 统一的 `StandardMaterial3D` 缓存（避免重复编译管线） |
| `scripts/world/` | `block_db` 方块表、`terrain_gen` 地形、`voxel_world` 区块与射线、`path_finder` A*、`texture_atlas` 程序化贴图 |
| `scripts/units/` | `flyer`/`rover` 两种单位、`unit_controller`（每帧注入传感器 + 跑 VM）、`unit_db` 单位表、`presets/` 预设玩家代码 |
| `scripts/buildings/` | `building` 建筑实体（施工剖面、地基校验、烟囱/圆环动画）、`building_db` 建筑表 |
| `scripts/economy/` | `economy` 资源账本、`production` 配方计时 |
| `scripts/net/` | `protocol` 二进制帧、`snapshot` 快照、`net_session` UDP 会话、`mp_manager` 主机/客户端管理 |
| `scripts/ui/` | `hud` 状态与提示、`code_panel` 代码编辑器、`mp_panel` 联机面板 |
| `scripts/player/camera_rig.gd` | 自由视角相机（拖拽转视角、FOV、输入开关） |
| `scripts/lang/` | 玩家语言实现：`py_lexer` → `py_parser` → `py_compiler` → `py_vm`（无 Python 依赖、纯 GDScript） |
| `shaders/` | 自定义着色器（施工剖面 `construction.gdshader`） |
| `tests/*_test.gd` | headless 回归测试，`./run_tests.sh` 全跑 |
| `tests/preview/` | 截图脚本，`./tests/preview/render_all.sh` 重新生成 `docs/` 预览图 |

## 玩家代码怎么跟游戏通信

1. `UnitController.tick(delta)` 按「每秒 60 行」的预算推进 `PyVM`；
2. 推进到一段代码的开头时，把传感器快照注入 VM 全局变量（`pos/vel/hp/enemies/orders/res/...`）；
3. 玩家代码调用控制指令（`set_lift`、`set_velocity`、`drill`、`laser`、`shoot`、`build_here`…），VM 把它们写进 `controls` 字典；
4. 单位节点每个物理帧读 `controls` 施加力/开火/建造，并把 `block_dug`、`gun_fired` 信号交给 `main` 结算资源与伤害。

## 几条约定（踩过坑才写下来的）

- 玩家不能直接改世界：只能打**虚影标记**，真正的挖掘/放置/建造由单位代码执行。
- 建筑要施工 10 秒、占地每格底下必须有方块、体积里不能有方块，否则罢工（暗红）。
- 沙箱 VM 里没有 `import`/`class`/`lambda`/`try`，死循环靠行数预算兜住。
- 所有玩法参数（伤害、造价、周期、矿脉密度）都在 `data/` 的 JSON 里，改数值不用动代码。
