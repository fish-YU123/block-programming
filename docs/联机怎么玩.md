# 联机怎么玩（M6 第一版）

这一版是**局域网 / 直连 IP** 的两人对战：一台当主机，另一台加入。

## 怎么开

1. 两台机器都装好游戏（或者同一台机器开两个窗口，第二个用 `--path` 复制一份工程也能测）。
2. 主机：进游戏后按 **M** 打开联机面板 → 点「开房间」。
   - 默认端口 `27015`，面板上会显示「房间已开：端口 27015，等待别人加入」。
3. 加入方：按 **M** → 在输入框填主机的 IP（同一台机器填 `127.0.0.1`；局域网填主机的内网 IP，比如 `192.168.1.10`）→ 点「加入」。
4. 加入成功后 HUD 会提示「已加入房间：你是红方」，面板状态显示队伍。

## 谁是谁

- 主机固定**蓝方**，跑完整的游戏模拟（单位、战斗、生产都在主机上算）。
- 第一个加入的人是**红方**；之后再来的人两队交替。
- 客户端不跑模拟，只按主机 20Hz 的**快照**插值显示所有单位的位置/朝向。

## 在联机里写代码

- 客户端按 **C** 打开代码面板，面板里列的是**自己队伍**的单位（替身）。
- 改完点「应用代码 / ⌘+回车」，代码会通过 UDP 发给主机，由主机绑定到对应单位上执行。
- 主机自己在本地改代码就跟单机一样（直接生效）。

## 现在的限制（后续再补）

- 只同步**单位位置/朝向/电量**；玩家标记的虚影、建筑、方块破坏**还没同步**。
- 没有重连/加密/断线续玩；主机断开客户端会停在最后一帧。
- 快照走裸 UDP：丢包就跳过一帧（单位会平滑插值过去），不做重传。
- 单位数量多时快照会超过 MTU（约 50 个单位以上），这时需要分片（见 `docs/联机设计.md`）。

## 排错

- 「开房间失败」：端口被占用，换一个端口（目前面板写死 27015，可改 `scripts/net/net_session.gd` 的 `DEFAULT_PORT`）。
- 一直「正在连接」：检查两边防火墙是否放行了 UDP 27015，或换到同一网段。
- 状态显示「连接超时」：5 秒没收到主机快照，通常是主机那边卡住或者网络断了。
